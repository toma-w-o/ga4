GA4 Realtime · Multi-Account

Еднократна настройка (отнема ~3 минути)

  1. Отвори Google Cloud Console → Credentials (създай проект, ако нямаш).
  2. В същия проект, от API Library, активирай Google Analytics Data API.
  3. В Credentials → Create Credentials → OAuth client ID → тип Web application.
  4. В Authorized JavaScript origins добави адреса, от който отваряш тази страница (виждаш го долу, в полето "Текущ произход").
  5. Копирай получения Client ID (завършва на .apps.googleusercontent.com) и го въведи долу.
  6. Акаунтът, с който влизаш, трябва да има Viewer достъп до съответните GA4 properties.
Няма добавени акаунти. Влез с Google и добави GA4 Property ID отгоре.
Данните се дърпат директно от GA4 Realtime Data API, от твоя браузър, с твоя Google вход. Нищо не минава през чужд сървър. Обновява се на всеки 20 сек.
